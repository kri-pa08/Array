Selection sort 
Let's take an array {1, 7, 9, 2, 3, 0}
sorted array will be  = {0, 1, 2, 3, 7, 9}
What is selection sort?
ans: Different rounds, and in particular round we bring a smallest element and place it in right place 
for example: {65, 25, 12, 22, 11}
Round 1: write down all the elements
place the smallest value of the array and place it on the index 0 which is the starting index (placing means swaping).
Round 2: Now i = 1;
place the smallest value of the array and place it on the index 1 --> i ++
Round 3: Now I = 2;
same as step 3 but place it on the index 2
Round 4: Now i = 3; 
same but index 3
Round wise element movemnets in an array 
Round 1: i = 0 --> 65 will be swaped with 11 so array will be {11, 25, 12, 22, 65}
Round 2: i = 1 --> 25 will be swaped with 12 then array will be {11, 12, 25, 22, 65}
Round 3: i = 2 --> 25 will be swaped with 22 then array will e {11, 12, 22, 25, 65}
Round 4: i = 3 --> then it will check smallest element not found no swaping
then there will be no need to run round 5
